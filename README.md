
# CNN-Based Autonomous Driving Simulation

## About the Project
This project explores autonomous vehicle simulation using MATLAB, combining deep learning and computer vision to replicate key aspects of self-driving technology. It focuses on interpreting road conditions and traffic signs to support simulated driving decisions.

A pretrained GoogLeNet CNN is adapted through transfer learning for traffic sign recognition, while image processing techniques support lane detection and environmental analysis. These outputs are used by the control logic to simulate vehicle behaviour.

## Technologies Used
- **MATLAB** – Simulation and implementation
- **Deep Learning Toolbox** – CNN training and model adaptation
- **Computer Vision Toolbox** – Image processing and visual analysis
- **GoogLeNet** – Pretrained CNN for traffic sign classification
- **Transfer Learning** – Adapting the pretrained network to the target dataset

## Key Features
- Recognises traffic signs using a CNN-based classification model
- Detects road lanes through classical computer vision techniques
- Analyses visual features for weather condition classification
- Implements speed adjustment based on detected signs and environmental conditions
- Combines perception and control modules to simulate autonomous driving decisions

## Implementation Approach
The system integrates multiple modules to simulate how an autonomous vehicle processes visual information and responds to its surroundings.

- **Traffic Sign Recognition:** Uses a GoogLeNet model fine-tuned through transfer learning to classify traffic sign images.
- **Lane Detection:** Applies image processing and edge detection techniques to identify lane markings.
- **Weather Classification:** Analyses visual characteristics of road scenes to estimate environmental conditions.
- **Speed Control:** Uses predefined control logic to determine appropriate speed adjustments based on available perception outputs.
- **Driving Simulation:** Combines module outputs to demonstrate basic autonomous driving behaviour within MATLAB.

## Dataset
Traffic sign images and road scene data are used for model training, testing, and visual analysis. The traffic sign dataset supports CNN-based classification, while road imagery provides input for lane detection and environmental assessment.

## Results
The project demonstrates how deep learning and traditional computer vision can work together in an autonomous driving simulation. Traffic sign classification provides visual recognition capabilities, while lane detection, weather analysis, and speed control contribute to the simulated vehicle's decision-making process.

## How to Run
1. Install MATLAB and the required toolboxes.
2. Open the project folder in MATLAB.
3. Ensure the datasets and image files are available at the expected paths.
4. Open the main MATLAB script.
5. Run the script to execute the simulation.
6. Examine the outputs generated by the traffic sign recognition and other implemented modules.
